# Mendflow — требования и границы (seed спринтов 1–2)

Источник: ТЗ / план семестра. Площадка: https://mendflow.us.

## Назначение
Социальная и карьерная платформа: студент, университет, компания в одном пространстве.
Счастливый путь: регистрация → код почты → вход → проект/задача → пост → отклик → повторный вход → публичная ссылка `/p/`.

## Роли продукта
- Студент: лента, проекты, отклики, события.
- Компания: вакансии и отклики.
- Университет: курсы, клубы, обмен.
- Модератор: жалобы (вне демо ранних спринтов).

## Граница семестра
**Внутри:** три роли, почта, лента на сигналах, друзья/сообщения, проекты+канбан+`/p/`, вакансии, страницы вуза/компании, события, уведомления, базовые жалобы.  
**Снаружи:** нативные приложения, звонки, оплата, отдельный ML-сервис, офлайн, отбор резюме нейросетью, парсинг чужих сайтов вакансий.

## Метрики (для спринта 6)
| Метрика | Смысл | Порог / правило |
|---|---|---|
| impressions | Показы карточек | ≥100 к отчёту S6 |
| clicks / CTR | Клики; CTR=clicks/impressions | тир expanded при CTR≥0,06 и ≥15 показов |
| read_time_ms | Время чтения | среднее в отчёте |
| tier | test→expanded | правило выше |
| email_verified_rate | Доля подтверждённых почт | ≥20 verified users к S6 |
| job_funnel | views→applications | ≥10 views и ≥3 applications к S6 |

Если порог не достигнут — отчёт показывает **empty state**, без выдуманных цифр.

## План тестовых пользователей
1. **Конец S3:** 4 чистых аккаунта (по одному на участника). Рената проверяет строки в `users`.
2. **До демо S4:** +2 студента (Асылхан), +1 компания (Маруф), +1 вуз (Аделя). Рената — data-приёмка.
3. **К S6:** ≥20 verified users суммарно (каждый добирает тестовые/приглашённые).

## PDA / AI-ассистент (mendflow-s3 → деплой ~спринт 5)

Источник кода: локальная полная копия `Desktop/mendflow-s3` (не упрощённый Desktop/mendflow).
Включает: `api/ai.php`, `api/llm_lib.php`, модуль «Развитие» (`api/growth_*.php`, `js/growth.js`, `sql/30_growth.sql`…`37_*.sql`).

На спринте 3 задеплоенный ассистент **не** входит в приёмку.
К спринту 5: выкладка PDA на https://mendflow.us с `GROQ_API_KEY` на сервере; учебный репозиторий пополняется по зонам, без единовременной заливки всего s3.
