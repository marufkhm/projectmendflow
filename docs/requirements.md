# Mendflow — требования и границы (seed спринтов 1–2)

Источник: ТЗ / план семестра. Площадка: https://mendflow.us.

## Назначение
Социальная и карьерная платформа: студент, университет, компания в одном пространстве.
Счастливый путь: регистрация → код почты → вход → проект/задача → пост → отклик → повторный вход → публичная ссылка `/p/`.

## Роли продукта
- Студент: лента, проекты, отклики, события.
- Компания: вакансии и отклики.
- Университет: курсы, клубы, обмен.
- Модератор: жалобы (вне демо ранних спринтов).

## Граница семестра
**Внутри:** три роли, почта, лента на сигналах, друзья/сообщения, проекты+канбан+`/p/`, вакансии, страницы вуза/компании, события, уведомления, базовые жалобы, заливка PDA UI/API.  
**Снаружи:** нативные приложения, звонки, оплата, отдельный ML-сервис, офлайн, гарантия live-ответа внешнего LLM, парсинг чужих сайтов вакансий.

## PDA = опциональная функция
PDA = опциональная функция: обязательны заливка кода + UI «Развитие»/панель и деградация без GROQ_API_KEY (честный fallback). Live-ответ LLM — nice-to-have, не блокер S5/S7.

Источник кода: `Desktop/mendflow-s3` (`api/ai.php`, `llm_lib.php`, `growth_*`, `js/growth.js`, `sql/30_growth.sql`…`37_*.sql`).
На S3 задеплоенный ассистент не в приёмке. К S5 — заливка кода+UI; live LLM не блокер. S7 smoke: экран «Развитие» / fallback без ключа; live AI не обязателен для pass.

## Метрики (спринт 6) — не смешивать

### Четыре числа отчёта
| Число (что выводим) | Порог показа на отчёте | Что показывать если порог не пройден |
|---|---|---|
| impressions (показы) | ≥100 | empty / «мало данных» |
| CTR = clicks/impressions | показывать при impressions≥100 | empty вместе с блоком показов |
| read_time (медиана / распределение, мс) | без порога показа | при отсутствии сигналов — «нет чтений» |
| job funnel: views → applications | views≥10 и applications≥3 | empty / «воронка не набрана» |

### Не числа отчёта
| Правило | Смысл |
|---|---|
| verified ≥ 20 | Условие допуска к «полному» отчёту |
| CTR ≥ 0,06 и ≥15 показов на карточку | Правило tier ранжирования (не порог отчёта) |

На странице отчёта подпись: **«выборка учебная»**.
