# mendflow

Площадка: https://mendflow.us
Репозиторий сдачи: https://github.com/marufkhm/projectmendflow

## Команда и зоны
- **Маруф** — тимлид + backend (почта/API). 
- **Рената** — БД, бэкап, приёмка данных.
- **Аделя** — системный архитектор + UI/UX, SPA-роуты `/p/`, UX-приёмка.
- **Абылай** — fullstack лента (`index.html`, сигналы, рекомендации).

## Структура
```
docs/     требования, архитектура, контракты, UI/UX
api/      PHP API (по зонам)
sql/      схема и проверки
js/       клиент ленты
deploy/   nginx/ssl/spa/upload скрипты
```

## Спринты (кратко)
Проект идёт семь спринтов. Каждый спринт отвечает на один вопрос и заканчивается проверяемым результатом.

| № | Название | Что делаем простыми словами | Главный результат | Ответственные |
|---|----------|-----------------------------|-------------------|---------------|
| 1 | Старт репозитория | Заводим общий репозиторий: README, папки, правила (без паролей и ключей в git) | Репозиторий с README и каркасом `docs/ api/ sql/ js/ deploy/` | Все |
| 2 | Требования и метрики | Договариваемся, что строим, что не строим и как будем считать успех | `docs/requirements.md`: путь пользователя, границы MVP, метрики, план тестовых пользователей | Все |
| 3 | Основа продукта | Схема базы, регистрация с подтверждением почты (без кода войти нельзя), прототип ленты, публичные ссылки `/p/`, скрипт резервной копии | Рабочая регистрация и вход, лента «Рекомендации», `docs/ranking-hypothesis.md` | Все |
| 4 | Сквозной путь за 5 минут | Новый пользователь проходит весь путь на сайте. Перед показом обязательно делаем резервную копию базы | Демо: регистрация → код → вход → проект → пост → отклик → повторный вход → `/p/` | Все, приёмка по зонам |
| 5 | Три роли без дыр | Студент, компания и вуз проходят свои сценарии без обрывов. Если спринт 4 был зелёным, заливаем модуль «Развитие» (PDA) | Три рабочих входа, экран «Развитие», проверка числа подтверждённых пользователей | Все |
| 6 | Метрики ленты | Считаем 4 числа: показы, CTR, время чтения, воронка вакансий. Если данных мало, показываем «мало данных», а не придуманные цифры | Страница отчёта с подписью «выборка учебная» | Все |
| 7 | Релиз и защита | Выкладываем, проверяем, замораживаем код (после этого правок нет) и защищаемся | Сайт на `mendflow.us`, документы защиты, границы MVP | Все |

**Как читать термины**
- **Бэкап**: резервная копия базы и загруженных файлов.
- **403 без подтверждения**: пока пользователь не ввёл код из письма, сайт не пускает его внутрь.
- **`/p/`**: публичная ссылка на страницу, которую можно открыть без входа.
- **PDA («Развитие»)**: необязательный модуль. Достаточно залить код и экран, а живой ответ ИИ бонус.
- **Smoke**: короткая проверка, что главное работает после выкладки.
- **Code freeze**: после него код не меняем. Исключение только по решению тимлида.

PDA = опционально (live LLM не блокер); заливка ~S5; см. docs/requirements.md.
