# Mendflow (учебная сдача)

Площадка: https://mendflow.us
Репозиторий сдачи: https://github.com/marufkhm/projectmendflow

## Команда и зоны
- **Маруф** — тимлид + backend (почта/API). 
- **Рената** — БД, бэкап, приёмка данных.
- **Аделя** — системный архитектор + UI/UX, SPA-роуты `/p/`, UX-приёмка.
- **Абылай** — fullstack лента (`index.html`, сигналы, рекомендации).

## Структура
```
docs/     требования, архитектура, контракты, UI/UX
api/      PHP API (по зонам)
sql/      схема и проверки
js/       клиент ленты
deploy/   nginx/ssl/spa/upload скрипты
```

## Спринты (кратко)
1–2. Seed репо + требования/метрики/тестовые пользователи  
3. Архитектура, sql, прототип ленты, почта 403, SPA-роуты, бэкап-скрипт  
4. Сквозной сценарий (бэкап до демо; data/UX/API приёмка)  
5. Три роли без дыр  
6. Метрики ленты (с порогом данных)  
7. Выкладка + smoke → **code freeze** → защита (только речь)
